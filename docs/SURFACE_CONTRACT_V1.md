# SAP — Surface Schema V1

## Назначение

Универсальная разметка физических поверхностей в координатах исходной
фотографии. Это не товарная SEG/YOLO-разметка и не маска эффекта.

## Контракт

- `schema_version`: `sap-surfaces-v1`
- `source.source_id`: ID, производный от SHA-256
- `source.image_sha256`: SHA-256 исходного изображения
- `source.width`, `source.height`: размеры исходного изображения
- `source.pixel_policy`: `encoded-pixels-no-exif-transpose`
- `surfaces`: до 32 размеченных поверхностей
- `surface_id`: уникальный ID поверхности
- `material`: glass / metal / plastic / wood / unknown
- `quad_norm`: четыре нормализованные вершины TL, TR, BR, BL
- `reviewed`: подтверждение оператора
- `note`: комментарий оператора
- `manual_review_required`: true
- `training_approved`: false

## Геометрия

Координаты нормализованы в диапазоне 0..1 относительно исходного
изображения без EXIF-поворота. Четырёхугольник должен быть выпуклым,
не самопересекающимся и достаточно большим для устойчивой разметки.

Каждая плоская стеклянная панель размечается отдельно. При неизвестном
материале используется `unknown`, без статуса подтверждения.

## Инварианты

1. Исходные изображения и SEG/YOLO не изменяются.
2. Разметка привязана к SHA-256 исходника.
3. Документ с другим SHA-256 или размерами нельзя применять к исходнику.
4. Разметка поверхности не означает допуск изображения к обучению.
5. JSON строго проверяется, включая неизвестные и повторяющиеся поля.

## Следующие шаги

- Локальный визуальный Surface Editor с несколькими областями.
- Сохранение JSON в приватном хранилище с резервированием версий.
- Повторная загрузка разметки, drag-and-drop вершин, undo/redo.
- Передача подтверждённой геометрии в Glass Diffuse / Fluorescent.

Все реальные изображения, разметки и отчёты остаются вне публичного Git.
