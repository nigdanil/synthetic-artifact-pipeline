# ComfyUI custom nodes — запланировано, НЕ установлено

Этот каталог не содержит рабочего расширения. Не копируйте его в установленный `ComfyUI/custom_nodes/`.
Сначала нужен реальный JSON существующего workflow и сверка окружения. Затем отдельно реализуем Python-обёртки поверх `src/sapipeline` с соответствующими `NODE_CLASS_MAPPINGS` или актуальным интерфейсом ComfyUI.

См. `../docs/COMFYUI_INTEGRATION.md`.
